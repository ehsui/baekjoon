# 공부한 개념

동적 계획법

# 설명

동적 계획법 코드를 짜는 어려움보다 (점화식을 쓰는 것이 익숙치 않아 오래 걸리긴 했다. 이부분은 많이 연습해봐야 늘 것 같다. 고등학교 수학 배울 때는 잘 했는데.. ) , 10007로 나눈 나머지를 답변으로 한다는 점에서 오류를 많이 냈다.

첫 번째로는 아예 10007을 나누지 않았고
두 번째로는 마지막에만 10007로 나누어 오버플로가 났다.
세 번째로는 중간에 나누었지만, 딱 범위의 마지막인 1000에 오버플로가 나 long -> long long으로 자료형을 변경했다.

알고리즘 문제를 풀 때 답의 범위를 알고, 자료형을 선택하는 방법을 알아봐야겠다.

# 코드

```cpp
#include <iostream>
#include <cstring>

using namespace std;

long long cache[1001];

long long SOF(int n);

int main() {
	int n;

	cin >> n;

	memset(cache, -1, sizeof(cache));
	cache[1] = 1;
	cache[2] = 2;

	cout << SOF(n) % 10007;

	return 0;
}

long long SOF(int n) {

	if (cache[n] != -1) return cache[n];
	else {

		cache[n] = SOF(n - 1) % 10007 + SOF(n - 2) % 10007;
		return cache[n];
	}
}
```
