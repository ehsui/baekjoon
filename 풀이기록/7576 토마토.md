# 공부한 개념

BFS

# 설명

**1. 문제 풀기 전 고민한 사항**
토마토가 얼마만에 다 익는지에 대한 최소 일수를 알아야 함.
=> 모든 경로에 대한 최소 경로를 구해야함. 그 경로가 얼마나 걸리는 건지도 알아야 함.

[쉬운 최단 거리](obsidian://open?vault=%EB%A8%B8%EB%A6%BF%EC%86%8D&file=01.%20Project%2F%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%2F%EB%B0%B1%EC%A4%80%2F14940%20%EC%89%AC%EC%9A%B4%20%EC%B5%9C%EB%8B%A8%EA%B1%B0%EB%A6%AC14940)
이 문제를 응용하면 될 것같다 생각했다.

모든 경로에 대해 걸리는 만큼을 구하고 하나라도 방문하지 못한 경우 (0인 경우)에는 무조건 -1 출력이 필요.
여기서 문제점은 visited 배열을 따로 사용하지 않는다면 바로 익어있는 부분이라 dist가 0인 부분이랑 익지 못한 상황 0이 구분이 안된다는 것이다. 따라서 dist 2차원 배열을 따로 선언해 관리할 필요가 있다.

*날짜이기 때문에 배열명을 dist -> date로 변경*
dist배열을 구하고 모든 토마토가 -1이 아닐 때 자연수 중에 가장 큰 수를 출력하면 된다. (마지막으로 익는 토마토의 일수를 가져오는 것)


**2. 문제 푸는 중 고민한 사항**
시작 지점이 여러 개 라는 것이 문제가 됐다.
BFS를 돌리기 전에 queue에 처음부터 익어있는 토마토를 모두 넣었고, date를 업데이트 할 때 다른 시작점에서의 date가 더 작을 때는 date를 업데이트 하지 않는 if문을 작성하였다.
=> 하지만 이는 사실 필요없는 조건이었고, 문제 풀이 후 고민한 사항에 관련한 걸 작성했다.

BFS 한 번에 모든 date를 업데이트 하고, date 배열에서 최댓값 (가장 마지막에 익은 토마토의 날짜)를 출력하거나, date가 -1인 부분 (adj != -1 중에서)이 있을 경우에는 무조건 -1을 출력했다.

**3. 문제 풀이 후 고민한 사항**
문제 풀이 후 다른 분들의 결과를 보니 조금 시간이 오래 걸린 점을 확인 했다. (본인 92ms, 다른 분들은 30ms 미만)

그래서 첫 번째로는 BFS에 queue를 전달하는 방법을 값 전달에서 참조 전달로 바꾸었다.
```cpp
void BFS(queue<pair<int, int>>& q)
```

위 방법으로도 드라마틱하게 줄어들지 않아 AI에게 도움을 받았다.
AI가 제시한 문제 발생 원인은 BFS의 특성을 잘 이해하지 못한 탓이었다.

기존 코드에서 date를 업데이트하는 부분에서는 조건을 다음과 같이 작성했다. 
여러 시작 지점(익은 토마토)에서 BFS가 동시에 출발하니까, 어떤 경로가 더 빠르면 갱신돼야 하지 않을까라는 생각에서 나온 결과였다.
```cpp
if (date[nextY][nextX] == -1 || date[nextY][nextX] > date[currentY][currentX] + 1)
```

하지만 BFS는 한 지점에서 다른 모든 지점으로의 최단 거리를 구하며, BFS는 시작 지점이 여러 개일 때 한 지점 먼저 date를 업데이트 하는 게 아니라, 먼저 들어간 date를 먼저 계산한다. 

이로 인해 시작 지점에 상관없이 더 빠른 경로가 먼저 큐에 들어가며, date는 항상 처음 방문한 경로가 최솟값이다. 

따라서 조건문을 방문했는지만 확인하도록 수정했다.
```cpp
if (date[nextY][nextX] == -1)
```

*사실 드라마틱한 변화는 없었다 ㅎ.. 그리고 생각해보니 88ms 정도면 0.088s니까 사실 상관 없을 거 같다.. *

# 코드

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <utility>

using namespace std;


void BFS(queue<pair<int, int>>& q);

vector<vector<int>> adj;
vector<vector<int>> date;
int M, N;

int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(NULL);


	cin >> M >> N;
	adj.assign(N, vector<int>(M)); // N행 M열의 adj 배열
	date.assign(N, vector<int>(M)); // N행 M열의 date 배열

	// 격자 그래프 입력
	for (int row = 0; row < N; row++) {
		for (int col = 0; col < M; col++) {
			cin >> adj[row][col];
			date[row][col] = -1;
		}
	}

	queue <pair<int, int>> q;
	for (int row = 0; row < N; row++) {
		for (int col = 0; col < M; col++) {

			// 처음부터 익어있는 토마토 모두 queue에 삽입
			if (adj[row][col] == 1) {
				q.push({ col, row });
				date[row][col] = 0;
			}
		}
	}

	BFS(q);

	int maxDate = 0;
	for (int row = 0; row < N; row++) {
		for (int col = 0; col < M; col++) {
			if (adj[row][col] != -1) {
				if (date[row][col] == -1) {
					cout << -1;
					return 0;
				}
				else maxDate = maxDate < date[row][col] ? date[row][col] : maxDate;
			}
		}
	}

	cout << maxDate;

	return 0;
}

// date 계산
void BFS(queue<pair<int, int>>& q) {
	int dy[] = { -1, 1, 0, 0 }; int dx[] = { 0, 0, -1, 1 };
	int currentX, currentY, nextX, nextY;


	while (!q.empty()) {

		currentX = q.front().first;
		currentY = q.front().second;
		q.pop();

		for (int i = 0; i < 4; i++) {
			int nextX = currentX + dx[i], nextY = currentY + dy[i];

			if (nextX >= 0 && nextX < M && nextY >= 0 && nextY < N && adj[nextY][nextX] != -1) {

				// 방문한 적 없을 때만
				if (date[nextY][nextX] == -1) {
					date[nextY][nextX] = date[currentY][currentX] + 1;
					q.push({ nextX, nextY });
				}
			}
		}
	}

}
```
