# 공부한 개념

분할 정복

# 설명

[1074 Z](1074%20Z.md) 와 유사한 유형의 문제! (분할 정복)

종이를 잘라서 종이가 한 가지 색깔이 아닐 때는 answer 배열 (0과 1이 저장되어 있는 배열)에 반영을 하지 않고 더 작게 자르도록 했다.

핵심 부분
```cpp
			if (color != paperArr[i][j]) {
				paper(half, r, c);
				paper(half, r + half, c);
				paper(half, r, c + half);
				paper(half, r + half, c + half);
				return;
			}
```

종이의 첫 값을 기준값으로 정하고 그 값과 다르면 제대로 안 잘린 것으로 판명했다.

# 코드

```cpp
#include <iostream>
#include <vector>

using namespace std;

void paper(int size, int r, int c);
int paperArr[128][128];
int answer[2] = { 0, 0 };

int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(NULL);

	int N;

	cin >> N;

	for (int i = 0; i < N; i++) {
		for (int j = 0; j < N; j++) {
			cin >> paperArr[i][j];
		}
	}

	paper(N, 0, 0);

	cout << answer[0] << "\n" << answer[1];

	return 0;
}

void paper(int size, int r, int c) {
	// 4 분면으로 나누어서 
	// 각 사분면에 1과 0이 혼합된 자료가 있는 지 봐야 함.

	int half = size / 2;

	int color = paperArr[r][c];
	for (int i = r; i < r + size; i++) {
		for (int j = c; j < c + size; j++) {

			if (color != paperArr[i][j]) {
				paper(half, r, c);
				paper(half, r + half, c);
				paper(half, r, c + half);
				paper(half, r + half, c + half);
				return;
			}
		}
	}
```
