# 공부한 개념

좌표 압축
정렬

# 설명

## 1. 좌표 압축

좌표 압축 단어만 보고는 어떤 것을 하라는 건지 잘 이해할 수 없었다. 컴퓨터 그래픽스에서 배웠던 공간에서 좌표 정규화하는 느낌인가? 라는 생각을 하고 찾아보았다.

구글링해 보니 좌표 압축은 알고리즘 보다는 테크닉에 가깝다는 말이 있었다. 복잡한 문제를 해결하기 위해 써먹을 수 있는 도구 정도로 생각하면 좋을 듯 하다.

n개의 좌표를 정렬하고 그것의 인덱스를 그 좌표의 압축으로 생각하는 것이다. 따라서 가장 작은 값이 0, 가장 큰 값이 n이 되는 것이다.

*세그먼트 트리와 연계가 많이 된다하니 이 내용도 공부해야겠다.*


이 내용까지 안 상태로 코드를 작성했으나 아래의 문제를 접했다.
## 2. 시간 초과

출력해야하는 입력 벡터 값을 압축 벡터에서 찾아 그 인덱스를 출력하도록 코드를 작성했다. 처음에는 항상 써왔던 find 함수를 사용했으나 이것이 시간 초과의 원인이었다. 검색 범위인 압축 배열은 이미 sort를 통해 한 번 정렬된 상태이기 때문에 lower_bound, upper_bound를 사용할 수 있다.

이는 이진 탐색을 기반으로 하며 데이터가 정렬된 상태에서만 사용 가능하다. => O(log n)

[[Lower bound, Upper bound]]
# 코드

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;


int main() {

	ios_base::sync_with_stdio(false);
	cin.tie(NULL);
	long N, input;
	vector<long> v, v2;

	cin >> N;

	for (long i = 0; i < N; i++) {
		cin >> input;
		v.push_back(input);
		v2.push_back(input);
	}

	// 정렬
	sort(v2.begin(), v2.end());

	// 중복 요소 제거
	v2.erase(unique(v2.begin(), v2.end()), v2.end());

	vector<long>::iterator it;
	for (long i = 0; i < N; i++) {
		it = lower_bound(v2.begin(), v2.end(), v[i]);
		cout << it - v2.begin() << " ";
	}

	return 0;
}
```
