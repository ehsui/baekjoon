# 공부한 개념

그래프, BFS(너비 우선 탐색)

# 설명

그래프 구현 문제를 많이 접해봐야겠다고 느낀 문제. 자료구조 수업 이후로 제대로 구현을 해본 적이 없던 것같다.

이번 문제는 격자 문제 (like 미로찾기)로, 일반적인 그래프 표현 방식인 인접행렬 이나 인접리스트 방식이 아닌 쌩 배열로 문제를 풀었다. 이런 상황에서는 아래와 같이 갈 수 있는 방향을 미리 선언해 반복문을 돌리면 보다 깔끔하게 코드를 쓸 수 있다.

```cpp
		int dy[] = { -1, 1, 0, 0 }; // Y (행) 좌표 변화
		int dx[] = { 0, 0, -1, 1 }; // X (열) 좌표 변화
```

~~사실 문제를 풀면서 아래의 내가 쓴 코드가 인접행렬 방식인줄 알았다..~~

인접행렬, 인접리스트, 행렬 => 코드를 효율적으로 짜기 위해 이 3가지 방식을 선택하는 기준을 세우는 것이 필요하다.

인접 리스트:  간선의 개수에 비례하는 메모리만 차지
but: 노드 i와 노드 j가 연결된지 확인하기 위해서는 adj[i] 벡터를 모두 확인해야 하므로 시간 복잡도가 O(V)가 됨.

인접 행렬: 노드 i와 노드 j가 연결된지 확인하기 위해서 O(1) 의 시간 복잡도 
but: 간선이 없는 부분도 표현해야하므로 메모리 공간 낭비 가능성 존재

행렬: 특수한 경우에만 사용 가능 상하좌우랑만 연결되어 있다는 전제
=> 해당하는 경우에는 이 방법이 가장 빠를 수 있다.

하나의 방법이 무조건 유리한 것도 아니고, 무조건 이 경우에는 특정 방법을 써야하는 것도 아니기 때문에 문제를 풀어보면서 감을 익힐 것!

# 코드

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <queue>

using namespace std;

int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(NULL);

	int T, M, N, K;

	cin >> T;

	for (int t = 0; t < T; t++)
	{
		int cnt = 0;

		cin >> M >> N >> K;

		bool board[50][50] = {0};
		bool visited[50][50] = {0};

		queue<pair<int, int>> point_q;

		// 상 하 좌 우
		int dy[] = { -1, 1, 0, 0 }; // Y (행) 좌표 변화
		int dx[] = { 0, 0, -1, 1 }; // X (열) 좌표 변화

		int X, Y;
		for (int i = 0; i < K; i++) {
			cin >> X >> Y;

			board[Y][X] = 1;
		}

		for (int i = 0; i < N; i++) {
			for (int j = 0; j < M; j++) {

				// 배추가 있고 방문 x
				if (board[i][j] == 1 && visited[i][j] != 1) {

					cnt++;

					point_q.push({ j, i });
					visited[i][j] = 1;

					while (!point_q.empty()) {
						pair<int, int> current_point = point_q.front(); 
						point_q.pop();

						int current_x = current_point.first;
						int current_y = current_point.second;

						// 4가지 방향 (상, 하, 좌, 우) 탐색
						for (int k = 0; k < 4; ++k) {
							int next_x = current_x + dx[k];
							int next_y = current_y + dy[k];

							// 다음 좌표가 범위 내에 있는지 확인
							if (next_x >= 0 && next_x < M && next_y >= 0 && next_y < N) {

								// 다음 좌표에 배추가 있고 아직 방문 x
								if (board[next_y][next_x] == 1 && visited[next_y][next_x] == 0) {
									visited[next_y][next_x] = 1;
									point_q.push({ next_x, next_y });
								}
							}
						}
					}
				}
			}
		}

		cout << cnt << "\n";
	}

}
```
