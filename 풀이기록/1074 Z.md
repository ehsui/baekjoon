# 공부한 개념

재귀, [분할 정복](분할%20정복.md)

# 설명 

요 근래 풀었던 문제 중에서 가장 오랫동안 고민했던 문제인 것같다.
2차원 배열을 재귀적으로 4등분하면서 특정 좌표 `(r, c)`가 배열 전체에서 몇 번째로 등장하는지를 구하는 **Z 모양 탐색** 문제이다.


**핵심 아이디어**

내가 문제를 풀 수 있던 아이디어는, 배열을 4등분 했을 때 행과 열의 절반이 되는 기준 (코드에서는 int half에 해당한다.) 을 통해 r c의 위치를 상대적으로 알아내는 것이다. 

정리하면,
배열을 계속해서 4등분(4분면 분할)하여 r, c 좌표가 어느 사분면에 속하는지를 찾아 이동하고, 그 위치를 따라 전체 순서에서 얼마나 건너뛰어야 하는지를 누적해 나가는 것이다.

- `half`: 현재 배열의 한 변의 절반 크기 (사분면 분할 기준)
- `temp`: zeroNumber을 구하기 위해  더해야하는 기본 값 (크기: `2^(2*(N-1))`)
	- 1사분면이라면 temp
	- 2사분면이라면 더하는 값 없음
	- 3사분면이라면 temp * 2
	- 4사분면이라면 temp * 3
	만큼 더해야한다.
- `zeroNumber`: 현재 사분면의 시작 번호 (Z 탐색 순서 기준)
	예를 들어,
	다음과 같은 배열이 있을 때 0이 zeroNumber가 되며, 13을 찾아야 할 때 (r=4, c=3)는 지금 배열을 4등분했을 때, 4사분면을 기준값으로 바꾸어야하므로 zeroNumber = 12 가 된다.

결국 가장 작은 단위(1x1)가 될 때 `zeroNumber`가 원하는 좌표의 Z 순서 번호가 된다.
# 코드

```cpp
#include <iostream>
#include <cmath>

using namespace std;


int Z(int N, int zeroNumber, int r, int c);



int main() {
	int N, r, c;

	cin >> N >> r >> c;
	int size = pow(2, N);

	cout<< Z(N, 0, r, c);

	return 0;
}

int Z(int N, int zeroNumber, int r, int c) {

	// 단위 값
	int temp = pow(2, 2 * (N - 1));
	int half = pow(2, N - 1);

	if (c >= half) {
		// 4사분면
		if (r >= half) {
			r -= half;
			c -= half;
			zeroNumber += temp * 3;
		}
		// 1사분면
		else {

			c -= half;
			zeroNumber += temp;
		}
	}
	else {
		// 3사분면
		if (r >= half) {
			r -= half;
			zeroNumber += temp * 2;
		}
		// 2사분면
		else {
		}
	}

	if (N == 1) return zeroNumber;
	else return Z(N - 1, zeroNumber, r, c);
}
```
