# 공부한 개념

해시맵, 조합

# 설명

고등학교 때 배운 확통 개념을 써먹은 문제!! 이 문제의 차이점은 해빈이가 바지만 입고도 돌아다닐 수 있다는 것이다. 즉 상의(셔츠, 반팔)와 하의(청바지, 슬랙스)가 있다면 상의만 입은 날도 출력 케이스에 포함시켜야 한다.

따라서 고르지 않는 케이스를 추가해야하고, 새로운 종류의 옷을 만났을 때 초기 값을 2개로 설정했다  => ("고르지 않음", 추가할 요소1)

map 관련 문제로 3번째 문제인데, 이번주 내로 map을 stl 로 사용하는 것뿐만 아니라 깊게 맵 특성이나 시간 복잡도 등을 공부해볼 예정 

# 코드

```cpp
#include <iostream>
#include <unordered_map>
#include <set>
#include <string>

using namespace std;


int main() {
	string current_first, current_second;
	int T, n;

	cin >> T;

	for (int i = 0; i < T; i++)
	{
		unordered_map<string, int> wear;
		unordered_map<string, int>::iterator it;

		cin >> n;

		
		for (int j = 0; j < n; j++)
		{
			// Input ex) hat headgear
			cin >> current_first >> current_second;

			it = wear.find(current_second);

			// not choose도 있기 때문에 2로 설정
			if (it == wear.end()) wear.insert({ current_second, 2 });
			else wear[current_second] += 1;

		}

		int answer = 1;


		for (auto iter = wear.begin(); iter != wear.end(); ++iter)
		{		
			answer *= iter->second;
		}

		answer -= 1;

		std::cout << answer << "\n";
	}

	return 0;
}

```
