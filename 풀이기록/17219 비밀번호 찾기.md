# 설명

이 문제는 1620 (나는야 포켓몬 마스터 이다솜) 문제를 푼 뒤에 접한 문제이며, 1620에서 공부한 내용이 그대로 쓰여 금방 풀었던 거 같다. map 을 통해 아이디를 검색하는 것 뿐이었다. (1620을 풀기 전에 이 문제를 접했다면 1620이 더 쉬웠을 텐데...)

# 코드

```
#include <iostream>
#include <map>
#include <string>

using namespace std;

map<string, string> Id_password;

int main() {
	int N, M;
	string Id, Password;

	ios_base::sync_with_stdio(false);
	cin.tie(NULL);
	cout.tie(NULL);

	cin >> N >> M;

	for (int i = 0; i < N; i++) {
		cin >> Id >> Password;

		Id_password.insert({Id, Password});
	}

	map <string, string>::iterator it;
	for (int i = 0; i < M; i++) {
		cin >> Id;

		it = Id_password.find(Id);
		cout << it->second << "\n";
	}
	return 0;
}
```
