# 공부한 개념

너비 우선 탐색

# 설명

1차원 공간에서의 너비 우선 탐색으로 최단 경로를 찾는 문제다.

이 문제는 단순히 앞으로만 가는 것이 아니라, 선택할 수 있는 3가지 방법이 있기 때문에 다음과 같이 선언해 코드를 작성했다.
```cpp
// -1만큼 움직이거나, 1만큼 움직이거나, *2만큼 순간이동
int move[3] = { -1, 1, 2 }; 
```

문제를 풀면서, 뭔가 행동의 종류가 정해져있고, 플레이어가 하나를 골라서 하는 류의 보드게임이 생각났다. --> 아마 비슷한 결의 상황이라 그런 듯

확실히 2차원에서의 탐색을 하다가 1차원으로 넘어오니 코드를 짜는데 수월했던 것 같다.

# 코드

```cpp
#include <iostream>
#include <queue>
#include <vector>

using namespace std;

int main() {
	int N, K, current_point, next_point;
	int move[3] = { -1, 1, 2 };
	queue<int> q;
	vector<int> sec(100001, -1);

	cin >> N >> K;

	// 시작 지점
	sec[N] = 0;
	q.push(N);

	while (!q.empty()) {

		current_point = q.front();

		q.pop();

		if (current_point == K) break;

		for (int i = 0; i < 3; i++) {
			if (i == 2) next_point = current_point * 2;
			else next_point = current_point + move[i];

			if (next_point <= 100000 && next_point >= 0 && sec[next_point] == -1) {
				q.push(next_point);
				sec[next_point] = sec[current_point] + 1;
			}
		}
	}

	cout << sec[K];

	return 0;
}
```
